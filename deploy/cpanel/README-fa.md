# استقرار میلانو (Meelano) روی هاست اشتراکی cPanel — راهنمای کامل

اپ میلانو یک سرور **Node.js** است (پنل مدیریت + فروشگاه + API + همگام‌ساز MySQL).
هاست‌های اشتراکیِ cPanel معمولاً دو قابلیت لازم را دارند: **Setup Node.js App (Passenger)** و **MySQL® Databases**. این راهنما هر دو را راه می‌اندازد.

---

## ۱) ساخت دیتابیس MySQL در cPanel
1. cPanel ← **MySQL® Databases**
2. ساخت دیتابیس، مثلاً `myuser_meelano`
3. ساخت کاربر دیتابیس با رمز قوی، مثلاً `myuser_db`
4. در بخش *Add User To Database*: کاربر را روی دیتابیس با **All Privileges** اضافه کنید
5. آدرس هاست دیتابیس در cPanel‌های رایج همان `localhost` است (پورت ۳۳۰۶)

## ۲) استقرار کد
1. ریپو را روی هاست ببرید (git clone یا zip در File Manager) داخل پوشه‌ای مثل `~/meelano`
2. cPanel ← **Setup Node.js App** ← *Create Application*:
   - Node.js version: **22** (یا ۲۰ به بالا)
   - Application Mode: **Production**
   - Application Root: `meelano`
   - Application URL: دامنه/زیردامنه اصلی
   - Application startup file: **`deploy/cpanel/start.js`**
   - Environment Variables: `ADMIN_USER=admin` و `ADMIN_PASS=یک-رمز-قوی`
3. در SSH همان کاربر:
   ```bash
   cd ~/meelano
   npm ci
   npm run build
   ```
4. در همان صفحه Node.js App دکمه **Restart** را بزنید. حالا `https://your-domain.ir` فروشگاه و `/login` پنل است.

> اگر هاست شما Node.js Selector ندارد، سرویس روی Docker/VPS هم با همین مخزن بالا می‌آید (`docker build .` — ایمیج آماده است) و همه‌چیز یکسان کار می‌کند.

## ۳) اتصال پنل به دیتابیس میزبان (بخش اصلی)
وارد پنل شوید: **تنظیمات ← دیتابیس و اتصال به هاست (cPanel/MySQL)**

1. `host/port/نام کاربری/رمز/نام دیتابیس/پیشوند` را وارد کنید (پیشوند پیش‌فرض `pf_`).
2. **تست اتصال** ← پیام نسخه MySQL.
3. **ساخت، تطبیق و جایگذاری جداول** ← این دکمه:
   - ۱۵ جدول استاندارد میلانو را می‌سازد: محصولات، پست‌ها، کدهای تخفیف، پیام‌ها، درخواست‌های همکاری، استان‌ها، سفارش‌ها، **اقلام سفارش**، تراکنش‌ها، ممیزی، لاگ ورود، پوش‌نوتیف، کاربران، نشست‌ها، تنظیمات/rev؛
   - اگر جدولی از قبل باشد، **ساختارش با الگوی اصلی تطبیق** داده می‌شود (ستون جاافتاده → ALTER؛ اگر خواستید، rebuild با حذف و بازسازی)؛
   - دادهٔ فعلی پنل کامل داخل جداول **جایگذاری** می‌شود؛
   - همگام‌سازی زنده روشن می‌شود: هر تغییر پنل حداکثر تا ~۳ ثانیه بعد در MySQL هم نوشته می‌شود.
4. **بررسی سلامت** ← جدول وضعیت همه جداول (سالم/ناسازگار/ساخته‌نشده + شمار سطر).
5. **ترمیم خودکار** برای هر مورد معیوب؛ **جایگذاری کامل داده** برای sync دستی؛ **فراخوانی از میزبان** برای میزبان تازه‌ای که دیتابیسش از قبل داده دارد (انتقال/مهاجرت).
6. **قطع اتصال** هر وقت بخواهید؛ پنل بدون آسیب روی موتور محلی برمی‌گردد.

کانفیگ در `data/db-config.json` (مجوز ۶۰۰، خارج از گیت) ذخیره می‌شود و پس از Restart خودکار فعال می‌ماند. `/api/health` هم وضعیت `db.engine` را گزارش می‌کند (SQLite محلی یا MySQL هاست همگام) — اپ‌های اندروید و فروشگاه همین را در صفحه اتصال نمایش می‌دهند.

## ۴) نکات امنیتی و پشتیبان
- پوشه `data/` (دیتابیس محلی، کانفیگ، مدیا) باید از وب غیرقابل‌دسترس باشد؛ `deploy/cpanel/htaccess.example` را به `.htaccess` ریشه اضافه کنید (قانون `RedirectMatch 404 ^/data`).
- پشتیبان MySQL: cPanel ← Backup Wizard یا cron:
  ```bash
  30 3 * * * mysqldump -u myuser_db -p'PASS' myuser_meelano | gzip > /home/myuser/backups/meelano-$(date +\%F).sql.gz
  ```
- پس از اولین ورود، رمز `ADMIN_PASS` را از «تنظیمات ← تغییر رمز مدیر» عوض کنید (همزمان روی جدول `pf_users` همگام می‌شود).

## ۵) اپ‌های اندروید
APK «میلانو | فروشگاه» و «میلانو | پنل مدیریت» را نصب کنید؛ در صفحه اتصال، `https://your-domain.ir` را بزنید — اپ ابتدا سلامت سرور و نوع دیتابیس را چک می‌کند و سپس وصل می‌شود. دکمه «مشاهده دمو» بدون سرور هم نسخه نمایشی کامل را نشان می‌دهد.

## عیب‌یابی سریع
| مشکل | علت رایج | راه |
|---|---|---|
| Access denied for user | رمز/کاربر دیتابیس | در cPanel User → All Privileges را دوباره ببندید/باز کنید |
| Unknown database | نام کامل دیتابیس | پیشوند کاربر cpanel با `_` را کامل بنویسید (`user_db`) |
| جدول ناسازگار شناسایی شد | دیتابیس قدیمی/وردپرسی با همان نام | «ترمیم خودکار» یا تیک rebuild برای همان جدول |
| صف همگام‌سازی بالا می‌ماند | اتصال MySQL قطع شده | «بررسی سلامت» → «اتصال دوباره» (اعمال) |
